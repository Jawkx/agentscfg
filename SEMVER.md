# Semantic Versioning

This repo follows Semantic Versioning 2.0.0.

## Format

```
MAJOR.MINOR.PATCH
```

Optional pre-release and build metadata may be appended:

```
MAJOR.MINOR.PATCH-PRERELEASE+BUILD
```

## Increment rules

- **MAJOR**: incompatible API changes.
- **MINOR**: backward-compatible feature additions.
- **PATCH**: backward-compatible bug fixes.

## Pre-release tags

Use pre-release identifiers for incomplete or unstable versions, e.g. `-alpha.1`,
`-beta.2`, `-rc.0`.

## Build metadata

Build metadata (the `+...` suffix) does not affect version precedence.
